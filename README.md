# Slip3 Studios

Static site for Slip3 Studios, an independent app studio.

- `/` — studio site (Formation Lab, Starting 5 Trivia, The Fold, and Plonk coming soon)
- `/mike/` — Mike Sabens personal page

No build step. Deploy root is `public/`. Source images are in `raw/`; OG card sources are in `og-src/`.
