The idea

Daily games work when they are short, shared, and the same for everyone. Basketball fans didn’t have one built for them.

Every fan gets the same five players each day, so London and Los Angeles share one game and one leaderboard.

“This game is dangerous.”

tomtendo, in a five-star App Store review

What’s inside

  1. A ten-second shot clock.

    Answer fast for up to three points a question. The fourth quarter pays double.

  2. One game a day.

    Today’s five, a live leaderboard, and a box score built for the group chat.

  3. Careers and seasons.

    Career stats, shot charts and achievements turn a daily minute into a long game.
