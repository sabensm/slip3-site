Every frame is the real game.

Plonk’s App Store screenshots and preview video were rendered by the game itself. Here’s how, and why it was worth the trouble.

Store art for games usually starts as a mock-up: a screen arranged by hand, pieces placed where they look best, a score that was never earned. It looks great and promises a game that doesn’t quite exist. For Plonk, the rule was the opposite. Every screen in the App Store listing had to be the game as it ships.

A store studio inside the game

Plonk is built in Godot, so the store art is built in Godot too. A small “store studio” loads the real game scene inside a viewport sized to each device: 1206×2622 for the 6.3-inch iPhone, 1320×2868 for the 6.9-inch, and 2064×2752 for the 13-inch iPad, each with that device’s own safe-area insets. The iPad frames are real iPad layouts, not stretched phone shots.

Around that live screen, the studio draws the frame: a sherbet-colored backdrop, the set’s name on the same tag pill the game uses, and a headline set in SF Pro Rounded Heavy, the game’s own HUD face. One word in each headline becomes a clay sticker. The lines are written the way the game sounds: “Drop a piece… plonk!”

A scripted player, held to the rules

The preview video needed real merges and real combos. So a scripted player drags the aim and drops pieces onto their twins. It gets no help: every piece it drops is one the game actually dealt, the Next preview always shows the true next piece, and nothing is spawned into view.

Finding a good take meant searching random seeds until one hit the take’s goal, like a chain that ends in a watermelon, then recording that seed. The same seed reproduces the same take, frame for frame.

Even the pieces around the frames are real

The pieces tumbling across the seams between screenshots aren’t illustrations. They’re drawn by the game’s own piece renderer, using the same art the player sees. The first three frames form one wide panorama, lemon to berry to sky, so the strip in App Store search results reads as a single picture.

Why bother

A screenshot is a promise. If it’s the real game, the promise is easy to keep.

It also keeps the art honest over time. When the game changes, the store art is re-rendered from the new build rather than repainted by hand. The same tooling produced the screenshots on Plonk’s page and the social cuts for launch.
