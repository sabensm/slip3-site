November 13, 2026 · The Starting 5

A new game every night.

Every morning, The Starting 5 has a fresh NBA trivia game waiting, built overnight by an automated pipeline.

The overnight schedule

At midnight UTC, yesterday’s game closes and its daily champion is crowned. Two hours later, generation runs for the next game. If that run fails for any reason, a retry starts automatically at 6 AM UTC. Every game is ready well before its day begins at midnight UTC, when it goes live for everyone at once.

1. Pick the five

Each scheduled game either has its five players set in advance, or a plain-language theme, like “five former Celtics champions”, that a model turns into five specific names. Before anything else runs, every name is checked against the player database. A game is never built around a player the app doesn’t know.

2. Write the scouting report

For each of the five, the pipeline researches the player’s career with search grounded on basketball-reference.com: bio, college, draft night, teams, honors and the rest. That dossier is what the questions are written from.

3. Twelve questions that tell stories

All five dossiers go to the model with a detailed brief. The twelve questions should tell stories rather than recite stat lines, and each must have exactly one right answer among the five, so the model is told to test every question against all five players for shared teams, conferences and awards. Difficulty climbs by quarter, from casual fan to deep cut. Every player answers two or three questions, never twice in a row, and every question should be readable in two or three seconds, because the shot clock is ten.

4. Check it twice

Then come two layers of quality control: a rules check for structure, such as unused or over-used players, and a second, independent model call that reviews every question for factual accuracy and uniqueness. If either fails, all twelve questions are regenerated, up to three attempts. If all three fail, the game is flagged for human review instead of being published broken.

5. Done before breakfast

When the game is ready, an alert goes out. The same game then goes live on the web and in the iPhone app, which share one real-time backend, so the leaderboard, careers and streaks match everywhere.
